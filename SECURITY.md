# Security policy

## Reporting a vulnerability

Do not publish exploitable details in a GitHub issue or Discord channel. Use
GitHub's private vulnerability reporting form in the repository **Security**
tab. If that form is unavailable, contact the maintainer through the private
contact link shown in the application footer and ask for a private reporting
channel before sending technical details.

Include the affected URL or commit, impact, minimal reproduction steps and any
suggested mitigation. Do not access other users' rooms, exceed the smallest
request volume needed to demonstrate the issue, or retain data that is not
yours.

## Supported version

Only the currently deployed production version and the latest commit on
`main` receive security fixes.
